# Embedded visible-star catalogue

`visible.csv` is an adapted subset of the HYG Database v4.1 by David Nash. It contains
8,920 entries with apparent visual magnitude no greater than 6.5. The Sun is excluded,
proper motion is intentionally omitted, and missing B-V color indices are replaced with
0.65. Coordinates use the J2000.0 epoch and equinox and are stored in radians.

Source: https://github.com/astronexus/HYG-Database/tree/main/hyg/CURRENT
